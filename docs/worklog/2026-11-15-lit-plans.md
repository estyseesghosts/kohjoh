# PICA lighting and expanded lit-list caching

The final implementation moves DS diffuse, specular, shininess, ambient and
emission evaluation into a PICA vertex shader and caches expanded lit-list
positions. The earlier command-plan-only implementation is superseded.

## NORMAL-time semantics and exact arithmetic

NORMAL transforms the normal with the current fixed-point vector matrix
and latches an immutable lighting context. Later matrix/material changes do
not recolour it. Explicit COLOR and diffuse-as-colour replace the latch.
Shared strip vertices retain their original colour and polygon alpha.

The 16-byte vertex and 32-byte batch ABIs remain unchanged. Signed 14-bit
transformed normals occupy colour bytes and spare matrix/padding bits.
Lit draws use six clip matrices; unlit draws retain sixteen. Literal colours
can share the lit shader; cross-context strip vertices become literal RGBA.

The shader has 409 instructions and 94 float registers including constants.
Base-128 split dot products keep integer intermediates within float24's
17 significant bits. Specular squaring and division by 255 use exact integer
decompositions, followed by original rounding, saturation and byte expansion.

Enabled light direction/half components outside [-16384,16383], transformed
normals outside [-8192,8191], or exhaustion of the bounded 512-context table
use exact CPU colour evaluation without dropping geometry. CPU shadows are
otherwise evaluated only when consumed. Storage is bounded with no per-frame
allocation. Explicit debug dumps resolve packed colours to preserve KJD1;
shipping drawing uses no GPU readback or CPU rasterization.

## Cache lit geometry

Lit lists retain expanded object-space positions, not baked lit RGBA.
Matrix, NORMAL, material, COLOR, texgen, tests and primitive events execute
against current state. Partial/delta positions retain incoming coordinate
dependencies. Source-word validation is exact. Verify mode also checks the
expanded positions and event parameter offsets.

This removes the permanent lit+matrix rejection, including Ho-Oh. Lists that
explicitly establish literal colours retain the old baked cache. Cache
lookup and BEGIN avoid evaluating CPU lighting unless a scalar colour is
consumed. KJ_G3_CPU_LIGHTING selects the CPU oracle for testing.

[renderer architecture](https://github.com/estyseesghosts/coffeepot/blob/main/ctr/engineering/PICA200/renderer-architecture.md),
