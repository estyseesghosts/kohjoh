# FIFO cache input comparisons

Baseline: `4756c78`. Work takes place in a separate Git worktree, with a
private clone of the patched decomp and private SDK/output directories. The
main checkout's audio edits and generated files are not part of this change.

The supplied hardware observations describe a real CPU opportunity, but
some mechanisms already changed in `a5f2d14`: calls shorter than 16 words
bypass keys entirely, unlit keys use a 52-byte prefix, and the 63-word global
state stream replays live parameters. Short-call sampled residuals cannot
all be attributed to 412-byte keys in this revision. Audio preemption also
remains part of elapsed FIFO/game times.

This change compares retained cache inputs directly against live state.
Cache hits no longer clear, fill and compare a temporary key. Exact source
word validation remains in place. Misses still capture an entry snapshot
before decoding; lighting, texture generation, active/pending lights and
shininess retain their dependencies. There are no probabilistic hashes.

Rationale: Coffeepot's [CPU optimization](https://github.com/estyseesghosts/coffeepot/blob/main/ctr/engineering/cpu-optimization.md)
and [renderer architecture](https://github.com/estyseesghosts/coffeepot/blob/main/ctr/engineering/PICA200/renderer-architecture.md)
recommend removing repeated CPU copying with explicit cache validity. The
Old 3DS logs establish CPU pressure and spare GPU capacity, not the size of
this change's speedup.

Validation: `python tests/native/check_hotpaths.py --reference 4756c78`
passes randomized geometry/state differentials, cached/live verification,
profiled attribution, 10k matrix programs and dependency fixtures. A new
20k-key corpus checks every consumed snapshot byte against the serialized
comparison across lighting, texgen, entry dependencies and shininess modes.
Geometry hash stays `d511eb58d36aceeb`; matrix hash `894b2296a9950b41`.
Hardware improvement remains unmeasured.
